# Dice Game

A simple dice game built with React and styled using styled-components.

## How it Works

- Click the Play Now button on the start screen to enter the game
- Select a number from the given options
- Click on the dice to roll it
- If the selected number matches the dice roll, your score increases by that number
- If it does not match, 2 points are deducted from your score
- Use the Reset Score button to reset your score anytime
- Use the Show Rules button to view the game rules

## Tech Stack

- React.js
- styled-components

## Getting Started

1. Clone the repository

```
git clone https://github.com/Ayesha-zaheer-123/dice-game-in-react.git
```

2. Navigate to the project folder

```
cd dice-game-in-react
```

3. Install dependencies

```
npm install
```

4. Run the project

```
npm run dev
```
